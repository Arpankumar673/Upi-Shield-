Sequence Diagrams
Sequence 1 — Text Analysis
User -> UI: Paste message
UI -> Analyzer: Analyze(message)
Analyzer -> Preprocessor: Normalize
Preprocessor -> Detector: Extract signals
Detector -> RiskEngine: Indicator scores
RiskEngine -> Explainer: Score + indicators
Explainer -> Guidance: Recommendation
Guidance -> UI: EN + HI result
UI -> User: Threat dashboard
Sequence 2 — Screenshot
User -> UI: Upload screenshot
UI -> OCR: Extract text
OCR -> UI: Text
UI -> Analyzer: Analyze(text)
Analyzer -> RiskEngine: Score
RiskEngine -> UI: Result
UI -> User: Threat dashboard
Sequence 3 — UPI Intent
User -> UI: Paste UPI intent
UI -> Parser: Parse URI
Parser -> Analyzer: Payment context
Analyzer -> RiskEngine: Risk
RiskEngine -> UI: Score + reasons
UI -> User: Warning
